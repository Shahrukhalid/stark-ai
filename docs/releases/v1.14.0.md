# STARK AI 1.14.0

## New
- **Shortcut from any app.** Press ⌥ Option + ⇧ Shift + Space (macOS) or Alt + Shift + Space (Windows) anywhere: STARK AI comes forward with the full-screen assistant, ready to talk.
- **Vision and Wanda can use your apps** (Settings → Computer control, off until you turn it on). They can see an app's buttons and fields, click, type in any language and press shortcuts. Every single action shows an approval card first; E-STOP blocks them all.
- **Permissions that stay.** The Mac app is now signed with STARK AI's own stable identity, so macOS remembers microphone and Accessibility permissions across updates.

Installers are not notarized: on a Mac right-click → **Open** the first time; on Windows choose **More info → Run anyway**.
