# STARK AI 2.1.3

## Final Reliability & Concurrency Hardening Release

This patch release delivers comprehensive reliability corrections across cross-process publishing coordination, event loop non-blocking lock safety, release pipeline immutability and remote asset digest validation, downloader SSRF protection across alternate IP formats, and FFmpeg baseline comparison and two-pass normalization.

### Highlights & Fixes

- **Fail-Closed Cross-Process Publishing Locks.** Ensured `_interprocess_platform_lock()` and `_async_interprocess_platform_lock()` fail closed immediately on file creation or acquisition errors. Publication never proceeds without holding the mandatory operating-system platform lock.
- **Non-Blocking Asynchronous Coordination.** Eliminated blocking synchronous lock waits from the asynchronous event loop by implementing `_async_interprocess_platform_lock()`, allowing coroutines to progress smoothly while preserving atomic quota checks and deduplication guards.
- **Immutable GitHub Release Enforcement.** Release workflows verify whether a target release is already published. Published releases are treated as strictly immutable and protected from being overwritten by workflow reruns.
- **Remote SHA-256 Release Digest Verification.** Enhanced GitHub release publishing by downloading all uploaded release assets from GitHub storage CDN to a temporary verification environment and validating every asset against `SHA256SUMS.txt` via `sha256sum -c` before publishing.
- **Enhanced Downloader SSRF & Proxy Guards.** Expanded network safety checks to parse and block alternate IP literal formats (decimal integers, hex representations, octal encodings, dotted hex/octal parts, and IPv4-mapped IPv6). Validates user and environment proxy configurations upfront to prevent SSRF against internal proxy or metadata endpoints.
- **Comprehensive FFmpeg Baseline & Two-Pass Verification.** Added baseline vs. processed media comparisons for audio normalization, video color grading, and watermark overlays. Implemented support for genuine two-pass linear audio loudness normalization with explicit pass-1 parameter injection (`linear=true`), distinguishing dynamic single-pass limiting from linear two-pass normalization.
- **Full Compatibility & Identity Preservation.** 100% preservation of all STARK AI agents (Vision, Wanda, J.A.R.V.I.S., F.R.I.D.A.Y., E.D.I.T.H., ULTRON, JOCASTA, D.U.M.-E., U), HUD dashboard, styling, themes, existing user settings, databases, and media.
