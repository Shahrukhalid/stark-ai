# STARK AI 2.1.5

## Multi-Instance Concurrency, Complete Credential Sanitization & Two-Pass Video Normalization

This release stabilizes production multi-instance coordination, hardens credential redaction across URLs, headers, and OAuth flows, and adds comprehensive two-pass loudness normalization for both single-video and multi-video merge workflows in Video Studio.

### Highlights & Fixes

- **Transactional Database Lock Coordination & Lock Resolution.** Hardened `_resolve_lock_dir()` and integrated database-backed `PlatformLock` transactional coordination (`acquire_platform_lock()` / `release_platform_lock()`). Guarantees that separate application instances and separate data directories sharing the same database resolve the same lock directory, eliminating publishing race conditions and preventing duplicate posts. Lock failures fail closed and immediately block publishing.
- **Deep Credential, Header & Token Scrubbing.** Hardened `redact_url_credentials()` to sanitize sensitive query parameters (`access_token`, `api_key`, `secret`, `signature`, `session_id`, `client_secret`), OAuth fragments (`#access_token=...`), and HTTP headers (`Authorization: Bearer`, `Authorization: Basic`, `Cookie:`, `Proxy-Authorization:`) across multiline stack traces, exceptions, and API logs.
- **Two-Pass Audio Normalization for Single & Multi-Video Merges.** Video Studio now executes automated Pass 1 EBU R128 loudness measurement across both single videos and joined/concatenated videos. Transparently applies Pass 2 linear loudness normalization (`-14 LUFS`) and reports explicit status (`2-Pass EBU R128` vs `1-Pass Fallback`) and post-export loudness verification on completed jobs.
- **Complete GUI and Agent Identity Preservation.** 100% preservation of all 9 STARK AI agent personas, HUD dashboard, visual themes, responsive layouts, user configurations, databases, and third-party notices.
