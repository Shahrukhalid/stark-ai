# STARK AI 2.0.0

## New
- **Media Acquisition & Downloader.** Acquire public web video, playlist streams, and audio extractions directly into your local library with live download progress and speed tracking.
- **Broadcast Audio Normalization.** Integrated EBU R128 loudness normalization (-14 LUFS) for social feeds and video exports.
- **Watermark Studio.** Overlay custom branding text on exported videos with configurable positions, fonts, colors, and background boxes.
- **Color Grading & Visual Adjustments.** Interactive brightness, contrast, and saturation controls in the Video Studio.
- **SRT Caption Tools.** Import and export standard SRT subtitle files directly from video transcripts and scripts.
- **Platform Publishing Safety & Pacing.** Automated daily post quotas, pacing interval protection, and HTTP 429 rate-limit backoff across connected platforms.
- **System Keep-Awake.** Prevents computer sleep during long video exports and active rendering queues on Windows and macOS.

Installers are not notarized: on a Mac right-click → **Open** the first time; on Windows choose **More info → Run anyway**.
