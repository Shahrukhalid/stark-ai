# STARK AI 2.1.2

## Final Production Hardening Release

This patch release delivers end-to-end production hardening across networking, download file isolation, cross-process publishing concurrency, release automation transactionality, and media processing verification.

### Highlights & Fixes

- **DNS Resolution Race & SSRF Elimination.** The socket connection guard directly establishes outbound connections to the pre-validated, publicly routable destination IP, preventing Time-of-Check to Time-of-Use (TOCTOU) DNS rebinding races. Extends coverage across IPv4, IPv6, IPv4-mapped IPv6, redirects, and all supported yt-dlp networking backends.
- **Strict Per-Job Download File Ownership.** Replaced filename-substring cleanup with strict per-job file registration. Cancelling or failing one download job never unlinks unrelated files or already completed playlist entries.
- **Controlled Playlist Download Lifecycles.** Enhanced playlist integration tests with mocked extractor results and controlled lifecycles covering partial completion, cancellation, network failures, application restart recovery, and simultaneous downloads.
- **Transactional GitHub Release Publishing.** Releases are drafted, populated with all three installers (Windows, macOS Apple Silicon, macOS Intel), verified against cryptographic SHA-256 checksums, and audited for asset count and integrity before being published publicly.
- **Cross-Process & Multi-Instance Publishing Concurrency.** Implemented operating-system-level file locking and transactional database state checks, preventing multi-process or multi-instance race conditions across daily publishing quotas and 7-day content deduplication.
- **Comprehensive FFmpeg Property Verification.** Strengthened FFmpeg test suites to verify exact video dimensions, codec streams, filter behavior, image watermark presence, true-peak/LUFS loudness normalization, subtitle tracks, and bitstream decoding validity.
