# STARK AI 2.1.4

## Proxy Security, Two-Pass Studio Audio, Concurrency Verification & End-to-End Hardening

This maintenance and reliability release delivers critical security fixes for proxy credential redaction, automatic two-pass loudness normalization in Video Studio with post-export validation, multi-instance publishing lock coordination, and comprehensive end-to-end integration verification.

### Highlights & Fixes

- **Proxy Credential Redaction & SSRF Defense.** Added strict username, password, token, and credential stripping across proxy settings, error messages, exceptions, logs, and database job records via `redact_url_credentials()`. Authenticated proxy URLs (`http://user:pass@host:port`) are never leaked in error diagnostics or persistent state.
- **Automatic Two-Pass Broadcast Audio Normalization.** Video Studio automatically executes a high-speed audio-only Pass 1 measurement probe (`-vn -af loudnorm=...:print_format=json`) to extract true peak, integrated loudness, loudness range, and target offset when "Broadcast audio (-14 LUFS, 2-pass)" is selected. Pass 2 automatically applies linear normalization (`linear=true`) with the measured parameters, and measures and records the resulting output LUFS and true peak directly onto the job.
- **Cross-Process & Shared Database Concurrency Coordination.** Implemented canonical lock resolution via `_resolve_lock_dir()`, coordinating file locks across separate application instances, shared databases, and environment overrides (`STARK_LOCK_DIR`). Verified mutual exclusion between independent operating system processes, duplicate prevention across shared database instances, and automatic startup crash recovery for interrupted publications.
- **Single-File Acquisition Filename Cleanliness.** Fixed custom filename handling in the media downloader to cleanly strip redundant input extensions, preventing double-extension naming (`.mp4.mp4`).
- **Comprehensive End-to-End Regression Verification.** Added complete real-world functional tests exercising Vision and Wanda dialogue and handoffs, consent-gated memory isolation, streaming HTTP media acquisition, multi-operation video rendering with loudnorm and image watermarks, and cryptographic approval-gated social publication.
- **Complete GUI and Agent Identity Preservation.** 100% preservation of all STARK AI agents (Vision, Wanda, J.A.R.V.I.S., F.R.I.D.A.Y., E.D.I.T.H., ULTRON, JOCASTA, D.U.M.-E., U), HUD dashboard, visual themes, user configurations, databases, and third-party notices.
