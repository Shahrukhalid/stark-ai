# STARK AI 2.1.6

## Reliable media downloads, security updates and cleaner tests

A maintenance release from a full audit of the app.

### Fixes

- **Downloading from a link works on every install.** The video downloader is now part of the locked dependencies, so Docker images and `make setup` installs include it. Before, those installs could not download media from a link.
- **Consistent dependencies.** The project's requirements and its lock file now agree, so installs pass the dependency check. Bluesky's 300-character limit is still counted exactly as the platform's apps count it, including Hindi, Tamil and other scripts, and a test now keeps it that way.
- **Security update.** opentelemetry-api 1.45.2 fixes a slow-parsing issue in trace headers (CVE-2026-126360).
- **No known vulnerabilities in the web app's tooling.** The web unit tests now run on Node's built-in test runner, removing a development dependency with an unfixed advisory. `npm audit` reports 0.
- **Code clean-up.** Unused code removed and every lint check passes.
