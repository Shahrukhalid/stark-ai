# STARK AI 2.1.0

## New & Enhanced

- **Hardened Media Downloader & Harvester.** Comprehensive SSRF defense with DNS resolution checks, IPv4/IPv6 private address blocking, cloud metadata IP guards, restricted port enforcement, and runtime request/redirect interceptors.
- **Persistent Download Queue & Crash Recovery.** Download jobs are backed by relational storage (`DownloadJob`), automatically recovering interrupted tasks after application restarts, limiting concurrency, and preventing file collisions.
- **Global E-STOP Integration.** Global emergency stop immediately halts active downloads, clears temporary `.part` and `.ytdl` files, and marks tasks cancelled.
- **Publishing Policy Real Execution Enforcement.** Connected `publishing_policy` directly into the `publish_item` execution pathway and automated scheduler, enforcing daily post quotas, minimum gap pacing, and HTTP 429 rate-limit backoff.
- **Content Deduplication Guard.** Prevents accidental double-posting using SHA-256 content fingerprints across a 7-day rolling window per platform.
- **Extended Video Studio & Gamma Slider.** Interactive gamma correction slider (0.5× to 2.0×), image watermark/logo overlay with configurable opacity and scale, and real-time media library refresh upon download completion.
- **Media Metadata Inspector.** Pre-flight URL inspection to view title, author, duration, thumbnail, and playlist entries prior to launching downloads.
- **Specialist Agent Media Tools.** Registered `media.download`, `media.analyze`, `video.process`, `video.thumbnail`, and `publishing.health` tools across U, Vision, Wanda, and J.A.R.V.I.S. with strict permission controls.
- **Automated CI/CD Release Safety Gate.** Explicit dependency gating in GitHub Actions ensuring release tags and desktop builds only trigger after all CI and security workflows pass.

Installers are not notarized: on a Mac right-click → **Open** the first time; on Windows choose **More info → Run anyway**.
