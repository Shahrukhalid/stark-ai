# STARK AI 2.1.1

## Hardening & Stability Release

This release hardens the media acquisition pipeline, guarantees concurrency safety across social publishing, establishes fail-closed automated release gates, and coordinates desktop installer distribution.

### Highlights & Fixes

- **Fail-Closed Release Gating.** The release workflow (`tag-release.yml`) now enforces strict verification against CI completion, failing closed on timeouts, cancellations, missing runs, API errors, and mismatched commit SHAs. No tag or release is created without explicit passing CI verification.
- **Concurrent Cancellation Isolation.** Downloader cancellation cleans up only partial and temporary files belonging strictly to the targeted download job. Concurrently running downloads and temporary files are fully isolated and protected against deletion.
- **Persistent Queue Recovery & Execution.** Restored queued download jobs now receive valid cancellation events on application startup, enabling worker threads to execute restored queues seamlessly. Interrupted running jobs transition cleanly to an interrupted status in the database.
- **Comprehensive Playlist Tracking.** Every file in a multi-video playlist is tracked, checked for existence and valid size, persisted in database records, and published individually across the internal event bus.
- **Enhanced SSRF & DNS Rebinding Defenses.** Socket connection interceptors enforce private IP, loopback, and restricted port blocking at the socket creation layer, eliminating DNS rebinding vectors. External downloaders are disabled.
- **Concurrency-Safe Publishing Quotas & Deduplication.** Publishing gates use per-platform asynchronous locks, evaluating both published and in-flight publishing jobs to eliminate race conditions on daily quotas and content deduplication.
- **Unified Release Publishing.** GitHub Releases are published only after all three desktop installers (Windows, macOS Apple Silicon, macOS Intel) pass their respective build, smoke-test, and integrity checks.
- **Real FFmpeg Integration Test Suite.** Added live test coverage executing real FFmpeg processes for color grading, image watermarking, loudnorm audio normalization, and caption rendering.
